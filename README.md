# 简易 PDF 工具

在浏览器中调整 PDF 页面，并从 PDF 页面截取题目、重新编排和保存题目集。

## PDF 页面调整

1. 选择或拖入 PDF。
2. 对页面进行旋转、删除或上移/下移。
3. 点击“保存并下载 PDF”。

## 题目整理

1. 在“题目整理”区域选择 PDF。
2. 在预览页面上拖动鼠标框选一道题，点击“添加选框中的题目”。扫描版 PDF 也可以通过截图区域进行选取。
3. 使用题目卡片的上移/下移按钮调整顺序，也可以移除不需要的题目。
4. 点击“下载编排后的 PDF”导出题目集，或点击“保存到本机题库”在当前浏览器中保存并随时载入。

PDF 仅在浏览器中处理，不会上传到服务器。题库使用浏览器本机数据库保存，不会跨浏览器或设备同步。页面依赖 CDN 上的 PDF.js 和 pdf-lib，使用时需要联网。
